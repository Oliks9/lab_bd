# Release Notes

## 2026-05-27

## 1. Oracle: схема и бизнес-логика

- Реализована структурированная SQL-архитектура:
  - таблицы, индексы, функции, процедуры, триггеры, пакеты, представления, seed, миграции, тесты.
- Расширен `pkg_admin`:
  - управление публикацией и черновиками;
  - настройка `show_feedback`;
  - настройка `attempt_limit`;
  - удаление вопросов/тестов с корректным пересчетом зависимых данных;
  - создание авторов, назначение ролей;
  - сброс прогресса пользователя (по тесту/полный);
  - смена пароля пользователя администратором (`set_user_password`);
  - отключение/включение аккаунта пользователем `ADMIN` (`set_user_active`);
  - удаление пользователя с защитными ограничениями (`delete_user`).
- Расширен `pkg_testing`:
  - режимы таймера `QUIZ` и `QUESTION`;
  - серверный автопереход на следующий вопрос (`expire_question`);
  - корректная финализация попытки и расчет процентов.

## 2. Миграции

- Добавлена миграция режима таймера теста/вопроса.
- Добавлена миграция timezone-aware полей попыток (`TIMESTAMP WITH TIME ZONE`).
- Добавлена миграция для `ORDERING` в option-based режим.
- Добавлена миграция лимита попыток на пользователя.

## 3. GUI и UX

- Улучшена структура экранов входа/регистрации и рабочих вкладок.
- Добавлены отдельные админ-действия:
  - смена пароля пользователя;
  - удаление пользователя;
  - сброс прогресса.
- Исправлены проблемы обновления UI после операций редактирования.
- Улучшено отображение и взаимодействие с ответами, включая `ORDERING`.

## 4. Качество и проверка

- Добавлены/обновлены smoke-тесты для:
  - авторизации;
  - контент-менеджмента;
  - прохождения тестов;
  - таймзон;
  - валидности Oracle-объектов.
- Сборка desktop-клиента в `dist/OracleQuizPlatform.exe` выполняется через `build/build_exe.ps1`.

## 5. Документация

- Обновлены `README.md` и `docs/*`.
- Добавлен полный технический справочник Oracle-логики (`docs/02_database_logic_map.md`) с деталями по:
  - таблицам и ограничениям;
  - процедурам/функциям/пакетам;
  - триггерам;
  - представлениям;
  - миграциям и тестам.
