# Release Notes

## 2026-05-27

### 1. Логика тестирования

- Исправлена обработка таймеров в режиме `QUESTION`.
- Добавлен автопереход к следующему вопросу по тайм-ауту.
- Скорректировано завершение попытки и фиксация статусов.

### 2. Результаты попыток

- Добавлен показ правильных ответов в итогах.
- Добавлен показ пояснений автора при включенном `show_feedback`.

### 3. Авторинг и управление контентом

- Реализовано редактирование уже созданных вопросов.
- Форма вопроса показывает только релевантные поля для выбранного типа.
- Добавлена возможность авторам добавлять категории.
- Добавлено мгновенное обновление списков тематик/категорий в UI без повторного входа.

### 4. Удаление и консистентность данных

- Авторы могут удалять собственные вопросы и тесты.
- Администратор сохраняет полный контроль удаления.
- Удаление теста сбрасывает статистику теста через удаление связанных попыток.
- Удаление вопроса пересчитывает порядок и агрегаты существующих попыток.
- Возврат опубликованного теста в черновик доступен автору/администратору.

### 5. Администрирование пользователей

- Добавлены операции:
  - сброс попыток пользователя по выбранному тесту;
  - полный сброс прогресса пользователя.
- Добавлено управление ролями и создание авторов через GUI.

### 6. Инфраструктура

- Поддержан запуск и проверка через Docker (`start`, `upgrade`, `check`).
- Обновлен процесс сборки EXE с учетом зависимостей `oracledb` и `cryptography`.
