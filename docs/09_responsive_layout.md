# Прокрутка и адаптивная разметка

Дата актуализации: 21.09.2026.

Форма подключения содержит отдельные вертикальные поля сервера, порта, типа
SID/Service name, имени базы, пользователя схемы и пароля. Она находится в общей
прокручиваемой области; при малой высоте окна кнопка «Подключиться» доступна прокруткой
или клавишей Tab. Дополнительный режим DSN скрывает основные поля адреса.
В «Публикации» переключатель доступа расположен в настройках черновика; вместо двух
кнопок сохранения теперь одна общая. Обе страницы включены в автоматические проверки
доступности элементов на разных размерах окна и масштабах Tk.

## Причина исправления

Tkinter `pack` распределяет свободное место между дочерними элементами.
Если большая таблица или форма получает место первой, следующие кнопки могут
оказаться сжаты до нескольких пикселей или полностью скрыты. Одного исправления
вкладки «Команда» недостаточно: высота зависит от текста, размера окна и DPI.

## Компоненты клиента

Общие механизмы находятся в `app/quiz_client/layout.py`. Они не обращаются к БД.

| Компонент | Назначение |
| --- | --- |
| `ScrollArea` | Контейнер Canvas с внутренней формой `content` и двумя полосами прокрутки. Внутренняя форма сохраняет требуемую ширину и высоту, даже если окно меньше. |
| `ScrollArea.resize` | Согласует размеры внутренней формы, окна Canvas и области прокрутки при изменении геометрии. |
| `ScrollArea.reveal` | Перемещает видимую область к полю или кнопке; для элементов шире окна показывает начало элемента. |
| `ScrollTable` | Treeview с собственными вертикальной и горизонтальной полосами. Метод `pack` размещает весь блок таблицы. |
| `flow_row` | Размещает группу кнопок/полей в несколько строк по доступной ширине. Возвращает функцию повторного размещения, например после изменения подписи кнопки. |
| `responsive_columns` | Ставит панели рядом при достаточной ширине, иначе друг под другом; ориентируется на ширину видимой области, а не длинной формы. |
| `scroll_event` | Направляет колесо мыши в ближайший прокручиваемый Canvas. На границе вложенного списка прокрутка может перейти к внешней странице. Shift выбирает горизонтальную ось. |
| `reveal_widget` | Последовательно показывает элемент во вложенных `ScrollArea` при получении фокуса. |

В `ui.py` метод `clear_page(scrollable=True)` создаёт прокручиваемую страницу,
а `admin_tab` создаёт прокручиваемую вкладку студии. Общие обработчики колесика
и фокуса устанавливаются один раз на окно приложения.

Таблицы, текстовые поля, списки и Combobox сохраняют свои стандартные обработчики
колеса. Прокрутка страницы не должна одновременно менять выбранное значение
или дублировать движение таблицы. Полосы прокрутки остаются доступными независимо
от положения указателя мыши.

## Охват страниц

| Страница | Поведение при нехватке места |
| --- | --- |
| Подключение, вход, регистрация | Прокрутка всей формы; группы нижних кнопок переносятся. |
| Каталог | Сохраняется отдельная панель запуска и прокручиваемое описание; таблица имеет обе полосы прокрутки. |
| Прохождение | Прокрутка длинного вопроса и вариантов; текст вариантов переносится. Кнопки ответа доступны внизу страницы и через Tab. |
| Результат, история | Прокрутка страницы, таблицы и доступ к нижним действиям. |
| Материалы | Панели тематик и категорий перестраиваются из двух колонок в одну. |
| Новый тест | Прокручиваемая форма; строки дополнительных параметров переносятся. |
| Вопросы | Редактор и список перестраиваются в одну колонку. Поля выбранного типа и кнопки доступны прокруткой. |
| Подбор | Прокрутка вкладки, перенос переключателей режима и кнопок. |
| Публикация | Прокрутка до настроек и выдачи доступа; строки действий переносятся. |
| Аналитика | Прокрутка до таблицы детализации, собственная прокрутка каждой таблицы. |
| Прогресс | Панели пользователей и тестов перестраиваются, кнопки сброса переносятся. |
| Команда | Сохранены отдельные формы создания и пароля; добавлена прокрутка всей вкладки как защита при нехватке высоты. |

Строка навигации отделена от заголовка и допускает перенос кнопок. В студии есть
список «Раздел студии»: это дополнительный способ выбора всех доступных разделов,
когда стандартные вкладки Notebook не помещаются по ширине. Список зависит от роли:
участнику студия недоступна, автору не добавляются «Прогресс» и «Команда».

## Ограничения и обновление

Прокрутка обеспечивает доступ к содержимому, но не обещает разместить всю длинную
форму одновременно. При высокой плотности полей может понадобиться и горизонтальная
прокрутка. Прохождение и таймер продолжают работать при прокрутке: оценивание,
дедлайны, права и сохранение ответов остаются в Oracle.

Новые компоненты включаются в EXE сборщиком через обычный импорт. Для переноса
исходников нужен весь каталог `app/quiz_client`, включая `layout.py`. Для готовой
сборки достаточно заменить `dist/OracleQuizPlatform.exe`; схема, пароли и сохранённые
попытки не меняются. Не запускайте `install.sql` ради исправления разметки.

Проверки и их границы описаны в `03_validation_and_demo_scenarios.md`, раздел 13.
