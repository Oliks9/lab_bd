# Матрица ролей и прав

Дата актуализации: 27.05.2026

## 1. Роли

- `USER` — проходит тесты и смотрит результаты.
- `AUTHOR` — создает и сопровождает контент своих тестов.
- `ADMIN` — полный контроль над пользователями и контентом.

## 2. Матрица основных операций

| Операция | USER | AUTHOR | ADMIN |
|---|---|---|---|
| Регистрация и вход | Да | Да | Да |
| Прохождение доступных тестов | Да | Да | Да |
| Просмотр своей истории попыток | Да | Да | Да |
| Создание тематики | Нет | Да | Да |
| Создание категории | Нет | Да | Да |
| Создание теста | Нет | Да | Да |
| Добавление/редактирование вопроса в черновике | Нет | Да (своего теста) | Да |
| Публикация теста | Нет | Да (своего теста) | Да |
| Скрыть опубликованный тест в черновик | Нет | Да (своего теста) | Да |
| Выдать доступ к закрытому тесту | Нет | Да (своего теста) | Да |
| Удаление вопроса | Нет | Да (своего теста) | Да |
| Удаление теста | Нет | Да (своего теста) | Да |
| Удаление категории | Нет | Нет | Да |
| Удаление тематики | Нет | Нет | Да |
| Создание автора | Нет | Нет | Да |
| Назначение роли | Нет | Нет | Да |
| Сброс попыток пользователя по тесту | Нет | Нет | Да |
| Полный сброс прогресса пользователя | Нет | Нет | Да |

## 3. Где проверяются права

- Проверки выполняются в Oracle в `pkg_admin`:
  - `require_editor`;
  - `require_admin`;
  - `require_quiz_owner`;
  - `require_quiz_manager`.
- GUI только вызывает процедуры и показывает сообщения об ошибках Oracle.

## 4. Особенности удаления

- Удаление теста:
  - удаляет связанные попытки (`attempts`) и статистику по тесту.
- Удаление вопроса:
  - запрещено при активных попытках (`IN_PROGRESS`) по тесту;
  - удаляет связи `attempt_questions`;
  - пересчитывает порядок вопросов и порядок отображения в попытках;
  - пересчитывает `awarded_points`, `max_points`, `score_percent` для затронутых попыток.

## 5. Поведение статусов теста

- Рабочий статус редактирования: `DRAFT`.
- Публикация: `PUBLISHED`.
- Операция «Скрыть в черновик» переводит тест из `PUBLISHED` обратно в `DRAFT`.
