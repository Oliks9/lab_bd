# Отчет по выполненной работе

Дата обновления: 27.05.2026

## 1. Цель проекта

Разработано настольное приложение для онлайн-квизов и тестирования, где основная бизнес-логика реализована в Oracle (SQL/PLSQL), а Python (Tkinter) используется как GUI-клиент и слой вызова процедур БД.

## 2. Что реализовано

- Структурированный проект с разделением по слоям:
- `sql/` для схемы, функций, процедур, триггеров, пакетов, представлений, seed-данных, миграций и тестов.
- `app/quiz_client/` для GUI, темы и доступа к Oracle.
- `docker/` для установки, апгрейда и проверок.
- Регистрация и вход пользователей по логину/паролю через серверные процедуры Oracle.
- Роли `USER`, `AUTHOR`, `ADMIN` с разграничением доступа на уровне пакетов БД.
- Начальная учетная запись администратора, создаваемая seed-скриптом.
- Управление учебным контентом:
- Тематики и категории.
- Создание тестов и вопросов автором.
- Публикация тестов и выдача доступа к закрытым тестам.
- Удаление/архивация контента администратором.
- Управление прогрессом:
- Сброс попыток пользователя по конкретному тесту.
- Полный сброс прогресса пользователя.
- Редактор вопросов:
- Редактирование уже созданных вопросов черновика.
- Динамические поля формы по типу вопроса (только нужные поля).
- Логика прохождения теста в Oracle:
- Запуск попытки.
- Проверка ответов.
- Подсчет баллов и процента.
- История попыток и детализация.
- Реализованы два режима таймера:
- `QUIZ`: время на весь тест.
- `QUESTION`: время на каждый вопрос.
- В режиме `QUESTION` при истечении времени вопрос автоматически пропускается и открывается следующий.
- Улучшен интерфейс:
- Раздельные страницы подключения, входа и регистрации.
- Более понятный экран прохождения теста.
- Более структурированная форма создания теста.
- В результате теста показываются правильные ответы и пояснения автора при включенном `show_feedback`.
- Docker-сценарии проверки и апгрейда без потери пользовательских данных.
- Сборка `exe` (PyInstaller) с учетом зависимости `cryptography` для `oracledb`.

## 3. Ключевые исправления по замечаниям

- Исправлена проблема с таймзонами (`TIMESTAMP WITH TIME ZONE`).
- Устранено некорректное завершение попытки при активном прохождении.
- Реализовано автоматическое обновление доступного контента в интерфейсе после добавления материалов.
- Добавлены административные операции удаления и сброса прогресса.
- Реализован автопереход на следующий вопрос при истечении времени вопроса.
- Добавлен показ пояснений автора в итоговой таблице результатов.

## 4. Итог

Получено полноценное учебное приложение в тематике программирования в базах данных, где критичная логика находится в Oracle, а Python выступает клиентской оболочкой.
